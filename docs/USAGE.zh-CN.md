# 使用指南

## 启动和输入

完整解压 `OpenBabelCN_Windows64.zip`，双击 `OpenBabelCN.exe`。保留 `engine`、`licenses` 等随包目录。程序面向 Windows 10/11 x64，无需另行安装 Python 或 Open Babel。

可通过文件选择或拖放添加输入文件，也可以在 SMILES 输入区每行输入一个分子，结构后以空格分隔名称。先确认输入格式，再选择功能和输出目录。

| 工作模式 | 适用任务 | 操作要点 |
| --- | --- | --- |
| 格式转换 | SDF、SMILES、MOL2、PDB 等格式互转 | 确认输出格式是否支持多分子；MOL 多分子输出需启用拆分 |
| 三维与优化 | 从结构生成坐标并进行能量最小化 | 缺少三维坐标时启用三维生成，选择适用力场和步数 |
| 对接格式 | 输出 PDBQT | 配体可选柔性模式，受体可选刚性模式；检查氢和电荷参数 |
| 分子属性 | 输出中文属性 CSV | 用于计算输入结构的属性；查看氢键计数、logP、TPSA 等 |

## 示例：乙醇属性

1. 输入 `CCO 乙醇`。
2. 选择“分子属性”，指定输出目录并开始处理。
3. 打开生成的 CSV。分子式应为 `C2H6O`，相对分子质量约为 `46.068`。

## 参数含义

- **氢处理**：保留、添加全部氢、极性氢、去除氢或按指定 pH 处理。三维生成及优化可能在内部加氢，明确选择去氢或极性氢时会在最终结构上再次处理。
- **坐标生成**：生成二维坐标用于绘图；生成三维坐标用于后续三维处理。二维结构不能直接用作需要三维坐标的优化或 PDBQT 输出。
- **力场**：用于能量最小化，所选力场需能够为该分子的原子类型提供参数。
- **部分电荷**：需根据后续用途选择模型和能保留电荷的输出格式。
- **最大连通片段**：保留分子的最大连通部分；使用前确认小片段是否包含有意义的组分。

## 输出与取消

任务输出放入带时间信息的任务目录，不同输入分别保存。当前输入成功完成后才提交其结果；取消或失败不提交该输入的部分结构，之前成功的输入结果保留。

中文 CSV 可用 Excel 等软件打开。诊断文件可能保留 Open Babel 的英文原始信息。二维窗口仅显示首个成功分子的示意结构，不能代替完整立体化学检查。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 单独复制 EXE 后无法计算 | 从发布包重新完整解压，恢复相邻 `engine` 目录 |
| 从 GitHub 下载后找不到 EXE | 去 Releases 下载 `OpenBabelCN_Windows64.zip`；Source code 是源码 |
| 多分子保存为 MOL 失败 | 启用单分子拆分，或选择 SDF 等支持多分子的格式 |
| 提示需要三维结构 | 启用三维坐标生成，或换用已有有效三维坐标的输入 |
| 力场或电荷处理失败 | 检查结构、元素、键型、形式电荷和模型适用范围，并查看诊断 |
| 未显示二维预览 | 预览限制 200 个重原子，且依赖二维坐标生成成功；查看输出文件及日志 |
| 任务超时或结构过大 | 每个输入最长 10 分钟；坐标生成和优化限制 500 个重原子，可尝试拆分或命令行处理 |
| 找不到某种读写格式 | 本构建禁用部分外部依赖，且各格式的读取/写入能力可能不同，以列表为准 |

反馈问题请使用仓库 Issues 模板，提供最小输入、所选参数和诊断。完整的原始操作文档见[使用说明.html](../使用说明.html)。
